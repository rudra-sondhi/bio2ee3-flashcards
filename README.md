### Revision modes

Every deck has a toggle at the top:

- **📚 Long revision** — the full deck: Q&A, MCQ, fill-in-the-blank, tables, diagram labelling.
- **⚡ Quick revision** — MCQ / no typing. Hides the fill-in and table cards for a fast pass.

Anki-style grading (Again / Hard / Good / Easy), ★ Priority filter for prof-flagged items, and past quiz + clicker questions throughout.

Works on phone and desktop · no login · progress saves in your own browser.
